Phase 2 — Qdrant vs in-memory ChunkStore coverage
Date: 2026-10-29

## What the 52 tests actually exercised

Lifecycle integration (`tests/integration/test_lifecycle.py`) uses fixture `store()`:
  try: make_local_chunk_store(...)
  except: InMemoryChunkStore(...)

`make_local_chunk_store` itself prefers `QdrantChunkStore.local(:memory:)` and only
falls back to `InMemoryChunkStore` if native client construction raises.

Therefore:
- **Passing lifecycle tests alone do NOT prove which backend ran** unless the test
  asserts `isinstance(store, QdrantChunkStore)`.
- Early Phase 2 evidence (`phase2_lifecycle.txt`) recorded an InMemory fallback when
  `cygrpc` import failed under Application Control.
- Re-check on 2026-10-29 (same host, no security changes):
    `make_local_chunk_store` → **QdrantChunkStore**
    upsert + count_for_doc against embedded `:memory:` → **OK**
