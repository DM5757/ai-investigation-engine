AI Investigation Engine

Retrieve, verify, and cite real passages from a 55k-document corpus. The system combines sources when needed, flags contradictions, and abstains when evidence is missing — it does not invent answers.

How to use this demo (about 1 minute)
  1. Pick a sample investigation below, or type your own question.
  2. Click Run investigation (or press Ctrl/Cmd+Enter). The request hits the live API.
  3. Read the status and answer, then open citations to inspect supporting quotes.
  4. Check Conflicts when sources disagree, and Investigation steps for multi-hop stages.
  5. If evidence is thin, expect insufficient — that is intentional abstention, not a crash.

Sample investigations

Production-verified cases. Selecting a chip fills the question; click Run investigation to execute against the live backend. Answers are never hardcoded in the browser.

Hybrid modes combine dense vectors with custom BM25 sparse search. Default matches production.
